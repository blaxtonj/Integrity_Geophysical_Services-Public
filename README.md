# Integrity Geophysical Services inc - Technical Case Study

## Overview

This project is a full redesign of one of the first professional websites I developed. The goal was to revisit the original implementation and rebuild it using a more structured, system-driven approach to frontend development.

The initial version prioritized functionality, but lacked clear visual hierarchy, consistency, and scalable patterns. This redesign focuses on improving usability, establishing a cohesive design system, and aligning the UI with modern frontend standards.

Due to proprietary business considerations, the full source code remains private. This case study highlights key architectural decisions, performance considerations, and design improvements made throughout the project.

[Live Site](https://www.integritygeophysical.com/)  
[Original Version](https://integrity-geophysical-services-2fd7y3v4u-blaxtonj.vercel.app/) 

## Context

Integrity Geophysical Services is a business-facing website designed to communicate specialized geophysical services to potential clients.

A key challenge in this redesign was balancing technical accuracy with clarity—ensuring domain-specific content remained credible while making the interface more intuitive and accessible.

The redesign also required modernizing the UI without introducing unnecessary complexity, prioritizing clarity, structure, and performance.
